# HireStream — Vercel Production Deployment Guide

## 1. Overview

The HireStream frontend is a React 19 Single Page Application built with Vite 7 and Tailwind CSS v4.  
This guide documents the exact configuration required to deploy the frontend to Vercel without encountering 404 routing errors or blank white screen crashes.

---

## 2. Vercel Project Configuration

When importing the `Hirestream` repository into the Vercel dashboard:

| Setting | Recommended Value | Notes |
|---|---|---|
| **Framework Preset** | `Vite` | Auto-detects Vite build outputs |
| **Root Directory** | `hirestream/frontend` | Points Vercel directly to the frontend package |
| **Build Command** | `npm run build` | Runs `tsc -b && vite build` |
| **Output Directory** | `dist` | Generated by Vite |
| **Node.js Version** | `20.x` or `22.x` | Supported LTS |

> [!NOTE]
> If you deploy with **Root Directory** set to `.`, the root-level `vercel.json` will execute `cd hirestream/frontend && npm install && npm run build` and output from `hirestream/frontend/dist`. Setting Root Directory to `hirestream/frontend` in the Vercel dashboard is the cleanest approach.

---

## 3. Environment Variables (Vercel)

Set the following in **Project Settings > Environment Variables**:

| Variable Name | Environment | Example Value | Description |
|---|---|---|---|
| `VITE_API_URL` | Production, Preview | `https://hirestream-backend.onrender.com` | Full HTTPS URL of the deployed Render FastAPI backend. **Do NOT include trailing slash.** |

---

## 4. Single-Page Application (SPA) Routing & Headers

The `hirestream/frontend/vercel.json` provides rewrite instructions and cache optimization headers:

```json
{
  "version": 2,
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ],
  "headers": [
    {
      "source": "/assets/(.*)",
      "headers": [
        {
          "key": "Cache-Control",
          "value": "public, max-age=31536000, immutable"
        }
      ]
    },
    {
      "source": "/(.*)",
      "headers": [
        { "key": "X-Content-Type-Options", "value": "nosniff" },
        { "key": "X-Frame-Options", "value": "DENY" },
        { "key": "X-XSS-Protection", "value": "1; mode=block" },
        { "key": "Referrer-Policy", "value": "strict-origin-when-cross-origin" }
      ]
    }
  ]
}
```

## 5. Deployment Verification Steps

After deployment completes:
1. Open the Vercel production URL (e.g., `https://hirestream.vercel.app`).
2. Verify that the homepage renders immediately with the Hero section and navigation bar.
3. Open browser Developer Tools (F12) -> Console: confirm there are zero uncaught exceptions.
4. Navigate to `/login`, `/recruiter`, and `/jobs/1`: confirm page transitions succeed without a white screen.
5. Perform a hard browser refresh (Ctrl+F5) on a nested route (e.g. `/login`): verify that Vercel serves the page without 404 errors.
